# Café Tan 90° — cafetan90.in

Informational, single-page website for Café Tan 90°, a 100% vegetarian café at Canada Corner, Nashik.

- Static site: `index.html` + `img/` — no build step.
- SEO: schema.org CafeOrCoffeeShop + FAQPage JSON-LD, Open Graph tags, `sitemap.xml`, `robots.txt`.
- Hosting: Vercel (import this repo, framework preset "Other", then add the `cafetan90.in` domain).
